How transparency is computed
Each pixel's alpha is reduced by how purple it is.
Hue match: angular distance from a target hue (default 285°), softened by saturation & value.
Purple formula: p = max(0, min(R,B) − G); α' = α · (1 − p · strength).
Decontaminate subtracts the purple component from RGB so the remaining edges aren't tinted.
